Paso 1

Verifica y descarga

Mantente conectado a la misma red Wi-Fi que __HOSTNAME__. Cada unidad Ambrosia tiene una CA raíz diferente.

Antes de instalar: compara la huella SHA-256 de arriba con la tarjeta de identidad impresa o la consola física de la unidad. Una CA raíz puede autorizar sitios web en este dispositivo; no confíes únicamente en esta página HTTP o en su QR.

Elige tu dispositivo abajo. El botón de descarga correcto aparece dentro de sus instrucciones.

Paso 2

Elige tu dispositivo

Selecciona un sistema operativo para desplegar sus instrucciones completas.

iPhone / iPad · usa Safari
Descargar perfil para Apple
  1. Abre esta página en Safari. Otros navegadores no pueden completar la instalación del perfil de Apple.
  2. Toca el botón, elige Permitir y cierra el mensaje “Perfil descargado”.
  3. Abre Ajustes → General → VPN y gestión de dispositivos.
  4. En Perfil descargado, selecciona el perfil de la CA raíz de Ambrosia y toca Instalar.
  5. Escribe el código del dispositivo. Como la unidad generó el perfil localmente y no está firmado por un proveedor, iOS muestra un aviso de perfil sin firma. Confirma Instalar otra vez y toca OK.
  6. Ahora abre Ajustes → General → Información → Ajustes de confianza de certificados.
  7. Activa la confianza completa para la CA raíz de Ambrosia de esta unidad y toca Continuar.
  8. Regresa aquí en Safari y completa el Paso 3.

Instalar el perfil y activar la confianza completa son dos pasos obligatorios distintos. Un dispositivo administrado puede impedirlos.

Android 13+ / GrapheneOS / CalyxOS / LineageOS
Descargar certificado CA
  1. Descarga ambrosia-ca.crt y compara su huella SHA-256 con la referencia independiente del operador.
  2. Abre Ajustes → Seguridad → Más ajustes de seguridad → Cifrado y credenciales → Instalar un certificado → Certificado de CA. En algunos equipos, busca Instalar un certificado en Ajustes.
  3. Elige Instalar de todos modos, autentícate y selecciona ambrosia-ca.crt en Descargas.
  4. Si Android pregunta el uso, elige VPN y aplicaciones o Certificado de CA, nunca Wi-Fi.
  5. Regresa a Chrome y completa el Paso 3.

Los nombres cambian según la versión y la marca. Algunas aplicaciones ignoran CAs del usuario aunque Chrome sí las acepte.

macOS · Safari / Chrome
Descargar certificado CA
  1. Busca ambrosia-ca.crt en Descargas y haz doble clic. Debe abrirse Acceso a Llaveros.
  2. Si es necesario, pulsa Comando + Espacio, busca Acceso a Llaveros y ábrelo.
  3. Selecciona el llavero Sistema en Llaveros del sistema. Importa ahí el certificado y autentícate como administrador.
  4. Selecciona Certificados, busca la CA raíz de Ambrosia de esta unidad y verifica su huella SHA-256.
  5. Haz doble clic en la CA y despliega Confiar.
  6. Configura Secure Sockets Layer (SSL) y Política básica X.509 como Confiar siempre.
  7. Cierra la ventana del certificado y autentícate otra vez para actualizar.
  8. Confirma que aparezca como confiable y vuelve a abrir Safari o Chrome.
  9. Si usas Firefox, sigue también su apartado de abajo.
Windows · Chrome / Edge
Descargar certificado CA
  1. Descarga ambrosia-ca.crt y compara su huella antes de importarlo.
  2. Abre Inicio, escribe mmc, haz clic derecho y elige Ejecutar como administrador. Acepta Control de cuentas de usuario.
  3. En Microsoft Management Console elige Archivo → Agregar o quitar complemento.
  4. Selecciona Certificados a la izquierda y pulsa Agregar.
  5. Selecciona Cuenta de equipo, pulsa Siguiente, deja Equipo local y pulsa Finalizar.
  6. Confirma que Certificados (equipo local) aparezca en Complementos seleccionados y pulsa Aceptar.
  7. Abre Certificados (equipo local) → Entidades de certificación raíz de confianza → Certificados.
  8. Haz clic derecho en Certificados y elige Todas las tareas → Importar.
  9. En el asistente pulsa Siguiente → Examinar, selecciona ambrosia-ca.crt y pulsa Abrir → Siguiente.
  10. Confirma Entidades de certificación raíz de confianza, pulsa Siguiente → Finalizar y acepta el mensaje de éxito.
  11. Verifica que la CA raíz de esta unidad aparezca en Certificados.
  12. Vuelve a abrir Chrome o Edge. En Firefox sigue además su apartado.

Guardar la consola MMC es opcional; la CA permanece instalada. Las políticas de la organización pueden impedir la operación.

Linux · almacén de confianza del sistema
Descargar certificado CA

Abre una terminal, entra en Descargas y compara la huella mostrada antes de continuar:

cd ~/Downloads openssl x509 -in ambrosia-ca.crt -noout -fingerprint -sha256

Debian / Ubuntu / Mint / Pop!_OS

sudo apt update sudo apt install -y ca-certificates p11-kit sudo mkdir -p /usr/share/ca-certificates/ambrosia sudo cp ambrosia-ca.crt /usr/share/ca-certificates/ambrosia/ grep -qxF 'ambrosia/ambrosia-ca.crt' /etc/ca-certificates.conf || echo 'ambrosia/ambrosia-ca.crt' | sudo tee -a /etc/ca-certificates.conf sudo update-ca-certificates

El último comando debe indicar que agregó un certificado.

Arch / Garuda

sudo pacman -S ca-certificates sudo cp ambrosia-ca.crt /etc/ca-certificates/trust-source/anchors/ sudo update-ca-trust

Fedora / CentOS

sudo dnf install ca-certificates sudo cp ambrosia-ca.crt /etc/pki/ca-trust/source/anchors/ sudo update-ca-trust

Cierra todas las ventanas del navegador, vuelve a abrirlo y completa el Paso 3. Firefox puede requerir además el apartado siguiente.

Firefox / Thunderbird / LibreWolf

Primero completa las instrucciones del sistema operativo. Las aplicaciones de Mozilla pueden requerir un ajuste adicional.

macOS / Windows

  1. Escribe about:config en Firefox y acepta el aviso.
  2. Busca security.enterprise_roots.enabled y cámbialo a true.
  3. Reinicia Firefox y completa el Paso 3.

Android

  1. Si tu versión de Firefox no acepta CAs del usuario, instala Firefox Beta.
  2. Abre Menú → Ajustes → Acerca de Firefox y toca el logotipo cinco veces para activar el modo desarrollador.
  3. Regresa a Ajustes, abre Ajustes secretos y activa Usar certificados CA de terceros.
  4. Reinicia Firefox.

Linux

  1. Abre Ajustes de Firefox y busca dispositivos de seguridad.
  2. Abre Dispositivos de seguridad → Cargar.
  3. Ponle Módulo de confianza CA del sistema y selecciona la biblioteca p11-kit. Debian/Ubuntu x86_64 normalmente usa /usr/lib/x86_64-linux-gnu/pkcs11/p11-kit-trust.so.
  4. Confirma que aparezca el módulo, cierra el diálogo y reinicia Firefox.

La ruta del módulo cambia según distribución y arquitectura. Usa la ruta p11-kit de tu distribución si el ejemplo no existe.

Step 1

Verify and download

Stay connected to the same Wi-Fi network as __HOSTNAME__. Each Ambrosia unit has a different Root CA.

Before installing: compare the SHA-256 fingerprint above with the printed identity card or the unit’s physical console. A Root CA can authorize websites on this device, so do not rely only on this HTTP page or its QR code.

Choose your device below. The correct download button appears inside its instructions.

Step 2

Choose your device

Select an operating system to expand its complete instructions.

iPhone / iPad · use Safari
Download Apple profile
  1. Open this page in Safari. Other browsers cannot complete Apple profile installation.
  2. Tap the download button, choose Allow, then close the “Profile Downloaded” message.
  3. Open Settings → General → VPN & Device Management.
  4. Under Downloaded Profile, select the Ambrosia Root CA profile and tap Install.
  5. Enter your device passcode. Because this profile was generated locally and is not vendor-signed, iOS shows an unsigned-profile warning. Confirm Install again and tap Done.
  6. Now open Settings → General → About → Certificate Trust Settings.
  7. Enable full trust for this unit’s Ambrosia Root CA and tap Continue.
  8. Return here in Safari and complete Step 3.

Installing the profile and enabling full trust are separate required steps. Managed devices may block either step.

Android 13+ / GrapheneOS / CalyxOS / LineageOS
Download CA certificate
  1. Download ambrosia-ca.crt and compare its SHA-256 fingerprint with the independent fingerprint shown by your operator.
  2. Open Settings → Security → More security settings → Encryption & credentials → Install a certificate → CA certificate. On some devices, search Settings for Install a certificate.
  3. Choose Install anyway, authenticate, and select ambrosia-ca.crt from Downloads.
  4. If Android asks for a certificate use, choose VPN and apps or CA certificate, never Wi-Fi.
  5. Return to Chrome and complete Step 3.

Menu names vary by Android version and manufacturer. Some native applications ignore user-installed CAs even when Chrome accepts them.

macOS · Safari / Chrome
Download CA certificate
  1. Locate ambrosia-ca.crt in Downloads and double-click it. Keychain Access should open.
  2. If needed, press Command + Space, search for Keychain Access, and open it.
  3. Select the System keychain under System Keychains. Import the certificate there and authenticate as an administrator.
  4. Select Certificates, find this unit’s Ambrosia Root CA, and verify its SHA-256 fingerprint.
  5. Double-click the CA and expand Trust.
  6. Set Secure Sockets Layer (SSL) and X.509 Basic Policy to Always Trust.
  7. Close the certificate window and authenticate again to update the settings.
  8. Confirm the certificate is shown as trusted, then close and reopen Safari or Chrome.
  9. If you use Firefox, also follow the Firefox section below.
Windows · Chrome / Edge
Download CA certificate
  1. Download ambrosia-ca.crt and compare its fingerprint before importing it.
  2. Open Start, type mmc, right-click the result, and choose Run as administrator. Accept the User Account Control prompt.
  3. In Microsoft Management Console choose File → Add/Remove Snap-in.
  4. Select Certificates on the left and choose Add.
  5. Select Computer account, choose Next, leave Local computer selected, and choose Finish.
  6. Confirm that Certificates (Local Computer) appears in Selected snap-ins, then choose OK.
  7. Open Certificates (Local Computer) → Trusted Root Certification Authorities → Certificates.
  8. Right-click the Certificates folder and choose All Tasks → Import.
  9. In the wizard choose Next → Browse, select ambrosia-ca.crt, then choose Open → Next.
  10. Confirm the store is Trusted Root Certification Authorities, choose Next → Finish, and acknowledge the success message.
  11. Verify this unit’s Ambrosia Root CA appears in the Certificates list.
  12. Close and reopen Chrome or Edge. Firefox users must also follow the Firefox section.

Saving the MMC console is optional; the imported Root CA remains installed. Organization policies may block the operation.

Close every browser window, reopen the browser, and complete Step 3. Firefox may also require the section below.

Firefox / Thunderbird / LibreWolf

Complete the operating-system instructions first. Mozilla applications may require an additional setting.

macOS / Windows

  1. Enter about:config in Firefox’s address bar and accept the warning.
  2. Search for security.enterprise_roots.enabled and set it to true.
  3. Restart Firefox and complete Step 3.

Android

  1. If your Firefox version does not accept user CAs, install Firefox Beta.
  2. Open Menu → Settings → About Firefox and tap the Firefox logo five times to enable developer mode.
  3. Return to Settings, open Secret Settings, and enable Use third party CA certificates.
  4. Restart Firefox.

Linux

  1. Open Firefox Settings and search for security devices.
  2. Open Security Devices → Load.
  3. Name it System CA Trust Module and select the p11-kit trust library. Debian/Ubuntu x86_64 commonly uses /usr/lib/x86_64-linux-gnu/pkcs11/p11-kit-trust.so.
  4. Confirm the module appears, close the dialog, and restart Firefox.

The Linux module path changes by distribution and processor architecture. Use your distribution’s p11-kit path if the example does not exist.

Step 3

Check the secure connection

Open the test page. It must load with an HTTPS address and without a certificate warning or a manually accepted exception.

Check HTTPSOpen Ambrosia

If it fails, check the unit name, device date/time, local network, and whether full trust was enabled.

Remove this CA or recover after a reset

Remove the Ambrosia profile or Root CA from the same system store used above. Remove it from Firefox too if configured separately. After a factory reset, remove the old CA, verify the new fingerprint, and repeat this guide.
